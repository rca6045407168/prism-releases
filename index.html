Install — first launch

  1. Open the download and drag Prism into your Applications folder.
  2. Right-click Prism → Open → Open (it isn't App-Store-signed yet, so a normal double-click is blocked).
  3. If macOS says it's “damaged”, open Terminal and run:
    xattr -dr com.apple.quarantine /Applications/Prism.app
    then open it again.

Set up a model

  1. In Prism, go to Settings → Providers and add a z.ai API key — the free tier covers GLM-4.5-flash. Get one at z.ai.
  2. Then pick GLM-4.5-flash or GLM-5.2 (or Auto) in the model selector. Each person uses their own key.

Prism auto-updates itself once installed. Apple Silicon recommended.
